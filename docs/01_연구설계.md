# 01. 연구 설계 (현재 확정본)

> 최종 갱신: 2026-11-11 · 상태: **기만형 재설계(기만체)와 재보정 완료, PPO 구현 전**

## 1. 연구 질문과 가설

**연구 질문**: 판단의 질(강화학습)은 의사결정 속도(OODA 템포)의 열세를 얼마나 상쇄하는가?

- **이론 틀**: Boyd의 OODA에서 핵심은 단순한 속도가 아니라 **Orient(판단·해석)**의 질이다.
  여기서 강화학습은 Orient의 질을 높이는 것으로, 의사결정 주기 k는 템포로 대응시킨다.
- **원래 가설**: 특정 상황에서는 강화학습된 느린 에이전트가 이긴다.
- **재정의(합의)**: "이긴다/진다"가 아니라 **손익분기점(임계 지연 k\*)**을 찾는다.

| | 가설 | 검증 방법 |
|---|---|---|
| H1 | k=1에서 RL 추격자의 승률이 FSM보다 높다 | 비율 차이 검정 |
| H2 | k가 커지면 둘 다 승률이 떨어지지만, RL의 하락폭이 더 작다 | 로지스틱 회귀의 `에이전트×k` 상호작용 |
| H3 | 임계 지연 k\* > 1 | 보간 + 부트스트랩 신뢰구간 |
| H4 | k\*는 도망자 유형(=상대의 정교함)에 따라 다르다 | `에이전트×k×유형` 3원 상호작용. 유형은 능력 계층(무반응 → 반응 → 반응+기만)이므로 순서가 있는 비교로 해석 |
| H5 (탐색적) | 각 k에서 학습한 RL(RL-B)이 k=1에서 학습한 RL(RL-A)보다 k\*가 크다 | |

**k\*의 정의(유형별)**: RL 추격자의 승률이 **같은 유형에 대한 FSM(k=1)의 승률**까지 떨어지는 지연값.
유형마다 기준이 따로이므로, 유형 간 기저 승률이 달라도 k\* 비교는 공정하다.

## 2. 환경 (`ooda/config.py`의 `EnvConfig`)

| 항목 | 값 | 이유 |
|---|---|---|
| 격자 | 20×20, 장애물 약 10% (길이 2~5의 벽 조각, 고립된 칸은 메움) | 우회로가 있어 단순 직선 추격이 통하지 않으면서 수천 판을 빠르게 돌릴 수 있는 크기 |
| 배치 | **침투-차단**: 도망자는 0~2열, 추격자는 9~10열에서 출발. 출구 후보 3개는 오른쪽 가장자리(서로 맨해튼 거리 10 이상) | 무작위 배치와 결과 차이는 작고(e1), 군사적 해석(침투조 vs 차단 부대)과 가짜 출구의 의미가 분명함 |
| 출구 | 3개 중 1개만 진짜. 도망자는 알고 추격자는 모름 | 정보 불확실성이 있어야 Observe·Orient가 변수가 됨 (결정 3) |
| 시야 | 반경 3(7×7), 장애물이 가림, 양측 동일 | 정보 조건을 대칭으로 두어 차이가 판단과 템포에서만 나오게 함 |
| 이동 | 정지와 상하좌우 | |
| 속도 | 추격자는 매 스텝 이동, **도망자는 6/7**(7스텝 중 6번 이동) | 같은 속도면 추격자 1명은 원리적으로 잡을 수 없음(격자 cop number 2, 결정 5). 값은 보정으로 결정(5절) |
| 포획 | 같은 칸, 또는 서로 자리를 맞바꾼 경우 | 스쳐 지나가기 방지 |
| 승패 | 추격자: 포획 / 도망자: 진짜 출구 도달 또는 T=100 경과 | T를 짧게 두면 '버티기'로 변질됨(결정 8). 100이면 시간초과 약 0% |
| seed | 1개의 seed가 지도·출구·시작 위치를 모두 결정 | 모든 조건에 같은 seed 목록(공통 난수). 기만체 배치는 별도 난수라 기만체 유무와 무관하게 지도·시작 위치가 같음 |

### 기만체 (기만형 도망자만, 결정 10)
| 항목 | 값 |
|---|---|
| 출발 | 0~2열 중 **가짜 출구의 행 ±2** (가짜 출구는 진짜가 아닌 2개 중 무작위) |
| 행동 | 가짜 출구로 최단경로 직진, 추격자를 무시. 속도는 도망자와 같음 |
| 관측 | 추격자는 시야 안의 접촉이 진짜인지 기만체인지 **구분하지 못함** |
| 식별 | 추격자와의 경로거리가 **1 이하**(인접) 또는 자리 교차 → 기만체가 사라지고 추격자는 기만체였음을 앎 (`decoy_ident_dist`) |
| 소멸 | 식별되거나 가짜 출구에 도착하면 사라짐 |
| 승패 영향 | 없음. 포획·탈출과 무관하고, 오직 추격자의 관측을 통해서만 효과를 냄 |

## 3. 에이전트 (`ooda/agents.py`)

### 도망자 (규칙 기반, 매 스텝 결정) — 능력 계층
| 유형 | 행동 | 역할 |
|---|---|---|
| **돌진형(rush)** | 추격자를 무시하고 진짜 출구로 최단경로 직진 | 무반응 |
| **회피형(avoid)** | 최근 5스텝 안에 추격자를 본 적이 없으면 출구로 직진. 기억하고 있으면 추격자 4칸 이내 칸의 비용을 높인 우회 경로(Dijkstra)로 출구를 향함. 추격자가 보이고 2칸 이내면 거리를 최대화하는 쪽으로 도주(동점이면 출구 쪽) | 반응 |
| **기만형(deceive)** | 진짜 도망자는 회피형과 똑같이 행동하고, **기만체 1개**를 함께 운용 | 반응 + 기만 |

- 폐기한 기만형 v1(보이는 동안 가짜 출구로 향하는 척)은 `FeintEvader`로 남겨 e1~e5 재현에만 씁니다.

### 추격자 ① FSM (비학습 기준선)

**받는 정보**: 자기 위치, 지도, 출구 후보 3곳, 시야 안의 접촉(둘이면 가까운 쪽, 동점이면 무작위 — 진짜/기만체 구분 없음), 기만체 식별 사건.

| 모드 | 조건 | 행동 |
|---|---|---|
| 추격 | 접촉이 보이고, 추정 출구가 없거나 2칸 이내 | 접촉 위치로 최단경로 이동 |
| 차단 | 접촉이 보이고, 추정 출구가 있고, 3칸 이상 | 접촉의 예상 경로 위에서 내가 먼저(또는 동시에) 도착할 수 있는 가장 가까운 지점으로 |
| 탐색 | 접촉이 안 보임 | 추정 출구를 지킴 → 없으면 마지막 목격 지점 → 그것도 없으면 **6열 차단선을 7칸 간격 순찰 지점으로 위아래 왕복** |

- **목표 출구 추정**: 목격할 때마다 출구별 점수 `0.8 × 기존 + 이번 이동으로 그 출구까지 줄어든 거리`. 목격 2회 이상이고 최고 점수 > 0이면 그 출구로 추정.
- **판단 초기화 (결정 11)**
  - 기만체 식별 사건을 받으면: 출구 점수·목격 횟수·마지막 목격 위치를 모두 버림.
  - 직전 목격 이후 지난 스텝 수보다 경로거리가 먼 곳에 접촉이 보이면(물리적으로 불가능한 이동 = 다른 개체): 출구 점수를 초기화. 접촉이 하나뿐인 판에서는 일어나지 않음.

### 추격자 ② PPO (미구현, `docs/04_다음단계.md` 참고)
FSM과 같은 정보만 받습니다. 관측에 시야 안의 모든 접촉(구분 없음), 접촉 궤적(시간 감쇠), 식별된 기만체 위치를 포함합니다.
- (결정 15, 파일럿 중) 기억 채널 2개 추가: 마지막 접촉 위치(새 접촉 전까지 유지), 장기 접촉 궤적(반감기 약 69스텝). FSM의 '마지막 목격 지점'·누적 진척도에 해당하는 원자료이며, FSM의 출구 추정 규칙 자체는 넣지 않습니다. `train.py --obs-memory 0`이면 이전 8채널 관측.

## 4. 의사결정 주기 k (`ooda/runner.py`)

- 추격자는 **결정 시점에만** 관측하고 행동을 고릅니다. 그 사이에는 **관측 없이 직전 행동을 반복**합니다(방식 A, 결정 4).
- 결정 시점은 `floor(t/k)`가 바뀌는 스텝입니다. 그래서 분수 k도 규칙적인 패턴이 됩니다.
  - k=1 → 매 스텝 / k=5/4 → 5스텝 중 4번 / k=3/2 → 3스텝 중 2번 / k=2 → 2스텝마다 1번
- **k 목록**: {1, 5/4, 3/2, 2, 3, 4}. 1~2 구간을 촘촘하게 둔 것은 지연 효과가 이 구간에서 급격하기 때문입니다.
- 도망자와 기만체는 항상 k=1입니다. 도망자 속도(6/7)는 결정 주기가 아니라 **이동 빈도**이고, 모든 조건에서 고정입니다.
- 기만체 식별 사건은 다음 결정 시점의 관측으로 전달됩니다.

## 5. 기준선 보정 (`scripts/calibrate.py`, 결정 8·12)

- **손잡이**: 도망자 이동속도(세 유형 공통). 제한시간 T는 쓰지 않습니다.
- **주 분석**: 공통 속도 **6/7**로 FSM(k=1)의 **균등 혼합 승률만** 50%에 맞춥니다. 유형별 승률은 맞추지 않습니다.
  - 검증: 혼합 **49.7%** [48.6, 50.9]. 유형별 돌진형 57.0%, 회피형 48.4%, 기만형 43.8%.
  - 유형 순서(돌진 > 회피 > 기만)는 파라미터로 맞춘 것이 아니라 행동에서 나온 것으로, 보정한 모든 속도(3/4~19/20)에서 유지됩니다. 논문에서는 **조작 점검**으로 보고합니다.
- **강건성 점검**: 유형별 속도(돌진형 8/9, 회피형 6/7, 기만형 5/6)로 각 유형 50%에 맞춤 → 검증 50.2%, 48.4%, 49.5%로 모두 50±2%p 통과. 기저 승률 차이가 H4 결과를 만드는지 확인하는 용도.
- 보정용 seed(2,000,000번대)와 검증용 seed(3,000,000번대)는 서로 분리된 각 2,500판/유형.

## 6. 실험 조건 (본 실험)

| 조건 | 추격자 | 학습 시 k | 평가 시 k |
|---|---|---|---|
| H | FSM | – | 1, 5/4, 3/2, 2, 3, 4 |
| RL-A (강건성) | PPO | 1 | 1, 5/4, 3/2, 2, 3, 4 |
| RL-B (적응) | PPO | 각 k에서 따로 | 학습한 k와 같은 값 |

- RL 학습 시드 5개. 학습 때는 에피소드마다 유형을 무작위로 섞음.
- 평가는 조건(에이전트×k×유형)마다 **3,000판 이상**(회피형과 기만형의 차이가 k=1에서 약 4%p라서), 평가용 seed는 5,000,000번대.
- 분석: 로지스틱 회귀 `win ~ agent * k * evader`(로그 오즈 척도), Wilson 신뢰구간, k\*는 부트스트랩.

# 01. 연구 설계 (현재 확정본)

> 최종 갱신: 2026-11-11 · 상태: **FSM 기준선 보정 완료, PPO 구현 전**

## 1. 연구 질문과 가설

**연구 질문**: 판단의 질(강화학습)은 의사결정 속도(OODA 템포)의 열세를 얼마나 상쇄하는가?

- **이론 틀**: Boyd의 OODA에서 핵심은 단순한 속도가 아니라 **Orient(판단·해석)**의 질이다.
  여기서 강화학습은 Orient의 질을 높이는 것으로, 의사결정 주기 k는 템포로 대응시킨다.
- **원래 가설**: 특정 상황에서는 강화학습된 느린 에이전트가 이긴다.
- **재정의(합의)**: "이긴다/진다"가 아니라 **손익분기점(임계 지연 k\*)**을 찾는다.

| | 가설 | 검증 방법 |
|---|---|---|
| H1 | k=1에서 RL 추격자의 승률이 FSM보다 높다 | 비율 차이 검정 |
| H2 | k가 커지면 둘 다 승률이 떨어지지만, RL의 하락폭이 더 작다 | 로지스틱 회귀의 `에이전트×k` 상호작용 |
| H3 | 임계 지연 k\* > 1 | 보간 + 부트스트랩 신뢰구간 |
| H4 | k\*는 도망자 유형(=상황)에 따라 다르다 | `에이전트×k×유형` 3원 상호작용 |
| H5 (탐색적) | 각 k에서 학습한 RL(RL-B)이 k=1에서 학습한 RL(RL-A)보다 k\*가 크다 | |

**k\*의 정의(유형별)**: RL 추격자의 승률이 **같은 유형에 대한 FSM(k=1)의 승률**까지 떨어지는 지연값.

## 3. 에이전트 (`ooda/agents.py`)

### 도망자 (규칙 기반, 매 스텝 결정)
- **돌진형(rush)**: 추격자를 무시하고 진짜 출구로 최단경로 직진.
- **회피형(avoid)**: 추격자 주변 칸의 비용을 높인 우회 경로(Dijkstra)로 출구를 향함. 추격자가 2칸 이내로 붙으면 도주.
- **기만형(deceive)**: 추격자를 최근 3스텝 안에 봤으면 **가짜 출구**로 향하는 척하고, 시야에서 벗어나면 진짜 출구로 전환. 추격자가 2칸 이내로 붙으면 도주.

### 추격자 ① FSM (비학습 기준선)
| 모드 | 조건 | 행동 |
|---|---|---|
| 탐색 | 도망자가 안 보임 | 추정 출구가 있으면 그 출구를 지킴 → 없으면 마지막 목격 지점 → 그것도 없으면 **6열 차단선을 위아래로 왕복 순찰** |
| 추격 | 도망자가 보임 | 도망자 위치로 최단경로 이동 |
| 차단 | 도망자가 보이고, 목표 출구가 추정됨 | 도망자의 예상 경로 위에서 내가 먼저 도착할 수 있는 지점으로 이동 |

목표 출구는 도망자를 볼 때마다 각 출구까지의 거리가 얼마나 줄었는지(진척도)를 감쇠 누적해서 추정합니다.

## 4. 의사결정 주기 k (`ooda/runner.py`)

- 추격자는 **결정 시점에만** 관측하고 행동을 고릅니다. 그 사이에는 **관측 없이 직전 행동을 반복**합니다(방식 A).
- 결정 시점은 `floor(t/k)`가 바뀌는 스텝입니다. 그래서 분수 k도 규칙적인 패턴이 됩니다.
  - k=1 → 매 스텝 / k=5/4 → 5스텝 중 4번 / k=3/2 → 3스텝 중 2번 / k=2 → 2스텝마다 1번
- **k 목록**: {1, 5/4, 3/2, 2, 3, 4}. 1~2 구간을 촘촘하게 둔 것은 지연 효과가 이 구간에서 급격하기 때문입니다.
- 도망자는 항상 k=1입니다. 도망자의 이동속도(15/17)는 결정 주기가 아니라 **이동 빈도**이고, 모든 조건에서 고정입니다.

## 5. 기준선 보정 (`scripts/calibrate.py`)

- **손잡이**: 도망자 이동속도. 제한시간 T는 쓰지 않습니다(이유는 `02_설계결정_기록.md`의 결정 6).
- **주 분석**: 세 유형 **공통 속도 15/17**로 FSM(k=1)의 균등 혼합 승률을 50%에 맞춤.
  - 검증 결과: **49.9%** [48.8, 51.0]. 유형별로는 돌진형 51.6%, 회피형 39.2%, 기만형 58.8%.
- **강건성 점검**: 유형별 속도(돌진형 8/9, 회피형 6/7, 기만형 10/11) → 각 유형 50±2%p 통과.
- 보정용 seed(2,000,000번대)와 검증용 seed(3,000,000번대)는 서로 분리된 각 2,500판/유형.

## 6. 실험 조건 (본 실험)

| 조건 | 추격자 | 학습 시 k | 평가 시 k |
|---|---|---|---|
| H | FSM | – | 1, 5/4, 3/2, 2, 3, 4 |
| RL-A (강건성) | PPO | 1 | 1, 5/4, 3/2, 2, 3, 4 |
| RL-B (적응) | PPO | 각 k에서 따로 | 학습한 k와 같은 값 |

- RL 학습 시드 5개. 평가는 조건(에이전트×k×유형)마다 1,000판 이상, 평가용 seed는 5,000,000번대.
- 분석: 로지스틱 회귀 `win ~ agent * k * evader`, Wilson 신뢰구간, k\*는 부트스트랩.
